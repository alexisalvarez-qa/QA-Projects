# Casos de prueba de e-commerce

| ID | Escenario | Tipo | Prioridad |
|---|---|---|---|
| ECOM-001 | Inicio de sesión con credenciales válidas | Positiva | P0 |
| ECOM-002 | Inicio de sesión con contraseña inválida | Negativa | P0 |
| ECOM-003 | Inicio de sesión con campos obligatorios vacíos | Negativa | P0 |
| ECOM-004 | Agregar un producto al carrito | Funcional | P1 |
| ECOM-005 | Eliminar un producto del carrito | Funcional | P1 |
| ECOM-006 | El carrito refleja el producto seleccionado | Funcional | P1 |
| ECOM-007 | Checkout rechaza información obligatoria faltante | Negativa | P0 |
| ECOM-008 | Checkout acepta información válida | Positiva | P0 |
| ECOM-009 | Completar el flujo de compra | Fin a fin | P0 |
| ECOM-010 | Repetir checkout después de completar un flujo | Regresión | P1 |

Los resultados y evidencias de ejecución deben registrarse después de ejecutar las pruebas.

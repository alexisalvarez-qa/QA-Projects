# Login Bug Report

## Bug ID
BUG-001

## Summary

Login button does not respond after entering valid credentials.

## Environment

Chrome Browser — Windows 11

## Preconditions

User is on login page.

## Steps to Reproduce

1. Open login page.
2. Enter valid username.
3. Enter valid password.
4. Click Login button.

## Expected Result

User should access dashboard.

## Actual Result

No action occurs after clicking Login.

## Severity

High

## Priority

Medium

## Status

Open

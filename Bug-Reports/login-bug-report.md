# Login Bug Report

## Summary
Login button does not respond after entering valid credentials.

## Steps to Reproduce
1. Open login page
2. Enter valid username and password
3. Click Login button

## Expected Result
User should be redirected to dashboard.

## Actual Result
Nothing happens after clicking login.

## Severity
High

## Priority
Medium

## 3. Automatización UI — Python + Selenium

**Tipo:** Automatización de pruebas  
**Herramientas:** Python, Selenium WebDriver

### Contexto
Práctica independiente para convertir un escenario estable de inicio de sesión en una prueba automatizada y reproducible.

### Objetivo
Demostrar fundamentos de automatización UI: localización de elementos, interacción con formularios, esperas explícitas y assertions.

### Escenario
1. Abrir la página de inicio de sesión.
2. Introducir credenciales válidas.
3. Enviar el formulario.
4. Validar el estado de autenticación.
5. Cerrar el navegador.

### Evidencia
[Ver proyecto de automatización con Selenium](../Independent-Projects/Selenium-Python-Login-Automation/)

Incluye código Python y requirements.txt.

## Mi enfoque de QA

1. Comprender los requisitos y el comportamiento esperado.
2. Identificar riesgos.
3. Diseñar escenarios y casos de prueba.
4. Ejecutar y validar.
5. Documentar resultados y evidencias.
6. Reportar defectos de forma clara y reproducible.
7. Analizar resultados.
8. Identificar oportunidades de mejora.
